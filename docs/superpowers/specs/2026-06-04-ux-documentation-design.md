# 신규 시스템 UX 문서화 — 설계

날짜: 2026-06-04
상태: 승인됨

## 문제

최근 추가된 시스템(솔로 연계, 행운 부적, 다이아몬드 스킬 분기, 이벤트 투표,
개인별 루팅)이 게임 내 어디에도 문서화되어 있지 않다. 도움말 화면은 레거시
시스템만 다루고, 부적 상점 라벨은 `[불운 1회 방어]` 한 줄뿐이며, 스킬 분기
선택지는 이름만 보여 효과 비교가 불가능하다.

## 설계

### 1. 도움말 페이지 분할 — `ui/help_view.go`

`HelpScreen`에 `page int` 필드 추가. `[←/→]` 페이지 전환(경계 클램프),
`[H]/[Q]/[Enter]` 뒤로. 헤더 `── 도움말 (n/3) ──`.

- **1p 조작·기본**: 로비/탐험/전투/상점 키 + 직업 스탯 (기존 재배치)
- **2p 전투 시스템**: 솔로 연계 3종 트리거·효과·단절 규칙, 스킬 분기 구조
  (T1 자동 → T2 분기 → T3 자동 → T4 캡스톤), 협동 보너스·파티 콤보
- **3p 탐험·경제**: 이벤트 다수결 투표 + 태그 힌트, 보물방 개인별 3선택
  루팅, 행운 부적 동작(도박 손해 1회 무효, 고정 비용 제외), 기존 팁

### 2. 부적 상점 설명 — `ui/shop_view.go`

`itemTypeLabel`: `[불운 1회 방어]` → `[도박 손해 1회 무효]`.
부적 진열 시 하단 한 줄: 도박 실패 손해(HP/골드/저주) 1회 무효, 고정 비용은
그대로.

### 3. 스킬 분기 효과 미리보기 — `entity/skill_tree.go` + `ui/game_view.go`

`SkillNode.EffectLabel() string` 추가: `+12 ATK`, `+3 DEF`, `+20 최대HP`,
`스킬위력 +25`, `치명타 +15%`, `힐 +20`. 분기/브랜치 선택 라인에
`(효과)` 병기.

### 4. 코덱스 — `ui/codex_view.go`, `ui/lore.go`

- `allItems` += `"행운 부적"` (상점 입장 시 진열품 전체가 기록되므로 발견 가능)
- 몬스터 목록에 없는 고아 Mimic 로어 제거

## 테스트

- 도움말 페이지 이동 경계(0↔max 클램프) 테스트
- `EffectLabel` 전 효과 타입 테이블 테스트
- 코덱스 `allItems`에 행운 부적 포함 테스트
