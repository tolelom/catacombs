# Catacombs — 협동 정체성 디자인 (Coop Identity)

**Date:** 2026-05-03
**Status:** Draft, awaiting user review
**Scope:** 4클래스 역할 재정의 + 6쌍 클래스 페어 콤보 시스템. 솔로 모드는 자기 대상 축소판으로 호환.

## 동기

현재 4클래스(Warrior/Mage/Healer/Rogue)는 스탯·스킬트리만 다른 솔로 4명에 가까움. 멀티플레이 게임인데 "같이 할 이유"가 약하다는 것이 가장 큰 재미 구멍. 이 디자인은 클래스마다 명확한 역할(탱커/서포터/정찰/제어)을 부여하고, 두 클래스가 같은 턴에 협동기를 발동하면 보너스 효과(콤보)가 나오도록 해 멀티 정체성을 부각한다.

## 비목표 (Non-goals)

- 솔로 플레이어 소외 금지 — 모든 협동기는 솔로에서도 축소판으로 동작
- 새 자원/UI 시스템 최소화 — 협동기 풀은 단순 "전투당 1회" 모델
- 기존 스킬트리 변경 없음 — 협동기는 클래스 고유 패시브 슬롯
- 기존 밸런스 큰 폭 변경 없음 — 협동기는 추가 옵션이지 필수 아님

## 핵심 결정

| 결정 | 선택 | 이유 |
|---|---|---|
| 손댈 클래스 범위 | 4클래스 전부 | 멀티 정체성 가장 또렷 |
| 솔로 호환 방식 | 자기 대상 축소판 | 일관성, 구현 가벼움 |
| 콤보 모델 | 사전 정의 6쌍 페어 | 명확·예측 가능, 외울만함 |
| 비용 모델 | 협동기 전용 쿨다운 (전투당 1회) | 매 전투 1회 보장, 일반 스킬과 분리 |

## 4클래스 협동기

### Warrior — 도발 (Taunt)
- **멀티**: 1턴간 모든 적이 워리어를 우선 공격 타겟으로 선택. 워리어 DEF +50% 1턴.
- **솔로**: 자기에게만 DEF +50% 1턴 (가드 효과).
- **자원**: 전투당 1회.
- **AI 영향**: `combat.MonsterAI`에서 `s.taunters` 같은 세션 상태 확인, 도발 활성화된 워리어가 있으면 우선 타겟. 도발은 스턴/이동 불가 적에는 적용 안 됨(향후 확장).

### Healer — 신성 가호 (Divine Grace)
- **멀티**: 죽은 아군이 있으면 1명을 50%HP로 부활(런 전체 1회 한정). 죽은 아군이 없으면 파티 전체 30%HP 회복(전투당 1회). 자동 분기.
- **솔로**: 첫 사망 시 30%HP 자동 부활 패시브 발동(런 1회). 추가로 협동기 슬롯 발동 시 자기 30%HP 회복.
- **자원**: 전투당 1회 (회복 모드). 부활은 런 전체 1회 (회복과 별도 카운터).
- **분기 사유**: 콤보 발동을 항상 가능하게 하려면 협동기가 단일 액션이어야 함. 부활 모드를 회복으로 자동 다운그레이드해 빈 발동 막음.

### Rogue — 정찰 (Scout)
- **멀티 / 솔로 동일**: 다음 방의 종류(전투/상점/이벤트/보물)와 몬스터 구성을 미리 공개. 전투 외(`PhaseExploring`)에서만 사용 가능.
- **자원**: 층당 1회 (전투 풀과 무관).
- **정보 표시**: 탐험 화면 상단에 패널 추가 — `[다음 방] 전투 — 고블린×2, 슬라임×1` 또는 `[다음 방] 상점`. 보스/미니보스 층은 종류만 노출(이름은 가림).
- **콤보 발동 처리**: 전투 외 사용이라 같은 턴 페어 매칭이 어려움 → 정찰을 사용한 직후 진입한 첫 전투의 1턴에 다른 협동기가 같이 발동하면 콤보 성립으로 처리(특수 규칙).

### Mage — 결계 (Ward)
- **멀티**: 1턴간 파티 전원 받는 피해 -50%.
- **솔로**: 자기 1명만 받는 피해 -50% 1턴.
- **자원**: 전투당 1회.

## 6쌍 페어 콤보

같은 턴에 두 명이 협동기 사용 시 추가 효과 발동. 정찰은 위의 특수 규칙 적용.

| 페어 | 콤보명 | 추가 효과 |
|---|---|---|
| Warrior + Mage | **강철결계** (Iron Aegis) | 워리어 받는 피해 -75%(중첩 아닌 대체), 다음 턴 워리어의 첫 공격이 명중 시 받은 피해의 50%를 추가 반사 데미지로 부여 |
| Warrior + Healer | **성전사** (Crusader) | 신성 가호 회복량 2배. 워리어에게는 추가로 +50% (즉 워리어는 60% × 2.5 = 75% 회복 — 부활 모드면 부활자 풀피) |
| Warrior + Rogue | **급소 노출** (Expose Weakness) | 도발 효과 + 다음 턴 모든 아군 공격 치명타 확정 (CritChance 무시) |
| Mage + Healer | **성역** (Sanctuary) | 신성 가호 대상(부활자 또는 가장 HP낮은 아군)에게 1턴 무적 + 결계 해제 후에도 1턴 추가 -25% |
| Mage + Rogue | **환영진** (Mirage) | 결계 효과 + 다음 턴 모든 적 공격이 50% 확률로 빗나감 |
| Healer + Rogue | **독칼** (Venomous Edge) | 정찰 효과 + 다음 전투 시작시 모든 적에게 독 3턴 부여 |

### 중복·예외

- **3인 이상 동시 발동**: 페어가 여러 개 성립 가능 → 모두 발동(콤보 효과 누적). 예: W+M+H 동시 → 강철결계 + 성전사 + (M+H)성역 모두 발동.
- **같은 클래스 2명**: 콤보 발동 X (모든 페어는 서로 다른 클래스 조합)
- **솔로**: 콤보 발동 불가 (파티 1명). 협동기 본 효과만.

## 새 액션 / 자원

### `ActionCoop` (신규)
- 행동 선택 화면에 "5. 협동기" 추가
- 협동기가 사용 불가 상태(쿨다운/조건 미충족)면 메뉴에 회색 표시 + 사유 툴팁 (`이번 전투 사용 완료` / `전투 외 사용 불가` 등)
- 정찰만 `PhaseExploring`에서 사용. 나머지 협동기는 `PhaseCombat`만.

### 세션 상태 추가 (`game/session.go`)
```go
coopUsedThisCombat map[string]bool   // fingerprint → 이번 전투 사용 여부
healerReviveUsed   map[string]bool   // fingerprint → 런 전체 부활 사용
scoutUsedThisFloor map[string]bool   // fingerprint → 이번 층 정찰 사용
soloHealerRevived  map[string]bool   // fingerprint → 솔로 자동부활 사용
nextRoomPreview    *RoomPreview      // 정찰 결과 (다음 enterRoom에서 소비)
pendingCombos      []ComboTrigger    // 콤보 효과 다음 턴 처리용 큐
```

전투 종료 시 `coopUsedThisCombat` 초기화. 층 진입 시 `scoutUsedThisFloor` 초기화.

## UI 변경

- **HUD**: 행동 선택 화면 하단에 `협동기: ⚡사용가능 / ✓사용됨` 표시 (각 플레이어 본인용)
- **로그 강조**: 콤보 발동 시 골든 컬러 + `★ 콤보 [강철결계] 발동! ★`
- **정찰 패널**: `PhaseExploring` 화면 상단에 `[다음 방] ...` 박스 (정찰 미사용시 박스 자체 숨김)
- **솔로 힐러 자동부활**: 사망→부활 사이에 0.5초 멈춤 + `힐러의 신성한 가호로 일어섰다!` 로그
- **회색 액션**: 사용 불가 협동기는 메뉴에서 회색 + 단축키 무반응

## 단계별 구현 (Phase)

### Phase 1 — 협동기 4개 + 솔로 축소판
- `entity/coop.go`, `combat/coop.go` 골격
- `ActionCoop` 추가, 세션 상태 필드 추가
- 4개 협동기 효과 구현 (도발/신성가호/정찰/결계) — 본 효과만, 콤보 X
- 솔로 축소판 분기
- 단위 테스트: 각 협동기 효과, 솔로 분기, 자원 소비

### Phase 2 — 6쌍 콤보
- `turn.go`에서 같은 턴 ActionCoop 수집 → 페어 매칭 → ComboTrigger 큐잉
- `combat/coop.go`에 6 콤보 effect 구현
- 정찰 콤보 특수 규칙(직후 첫 전투 1턴)
- 테스트: 6쌍 발동 조건, 3인 동시 발동 누적, 같은 클래스 X

### Phase 3 — UI
- ActionCoop 메뉴 + 회색 처리
- HUD 협동기 상태
- 콤보 로그 강조 (스타일 추가)
- 정찰 패널

### Phase 4 — 메타 (코덱스 + 업적)
- 코덱스 콤보 탭 + 마이그레이션
- 3종 업적 + 트리거 와이어업

## 예상 위험 / 균형 고려

- **위험: 콤보 OP** — 강철결계 + 성전사 + 성역 동시 발동 시 워리어 사실상 무적. 보스전에서 너무 강할 수 있음. → Phase 2 후 플레이테스트, 필요시 콤보 효과 약화.
- **위험: 정찰 콤보 특수 규칙 혼란** — UX적으로 "정찰 사용 → 다음 전투 1턴에 다른 협동기 = 콤보"가 직관적이지 않을 수 있음. → 정찰 발동 시 로그에 `다음 전투 1턴 협동기 시 콤보 발동` 안내.
- **위험: 솔로 힐러 부활이 너무 강함** — 첫 사망 자동부활은 사실상 추가 라이프. → 30%HP로 약하게, 런 1회 한정으로 제한. 향후 데이터 보고 조정.
- **위험: AI 도발 적용 범위** — 일부 보스(고유 패턴 있음)는 도발 무시해야 보스전 의도가 살 수 있음. → `Monster.IgnoreTaunt bool` 플래그, 보스에 true.

## 명시적으로 안 함

- 새 클래스 추가 (4클래스 정체성부터 굳히기)
- 합체기/큰 컷신 (브레인스토밍에서 콤보 모델 A 채택, C는 보류)
- 태그 기반 자유 콤보 (모델 B 보류)
- 메타 진행, 보스 페이즈 깊이 — 별개 디자인 라운드
