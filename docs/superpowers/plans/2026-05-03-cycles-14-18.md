# Cycles 14–18 Plan

## Cycle 14 — Active Relics
유물이 모두 패시브. 1~2개 액티브 유물 추가 (전투 중 발동, 쿨다운). 예: "Smoke Bomb" 1턴 파티 회피+30%, "Bloodstone" 자기 30%HP 즉시 회복, "Time Glass" 다음 턴 액션 1번 더.

## Cycle 15 — Chat Emote Reactions
멀티 채팅이 텍스트만. 6~8 단축 emote 키(`/dance` `/cheer` `/laugh` 등) + 전투 로그에 공용 표시. 협동 분위기.

## Cycle 16 — Class Mastery (런 누적 클래스 경험치)
한 클래스 5/10/20런 클리어시 영구 +1 시작 스탯. 4 클래스 × 3 단계 = 12 마일스톤. souls와 별개 보상.

## Cycle 17 — Boss Trophy + Codex Boss Tab
보스 4종 처치 시 트로피 획득(컬렉션). 코덱스 새 탭 "보스" — 처치 횟수, phase 2 도달 횟수, 트로피 표시.

## Cycle 18 — Daily Modifier (일일 변이)
일일 도전이 매일 같은 시드만. 추가로 매일 무작위 modifier 1개 (예: "더블 골드" / "유리 대포" / "느린 적"). DailyDate 기반 결정. 리더보드 비교 공정.

각 사이클 1 커밋, 매 사이클 후 빌드 + 테스트.
